.. _manifest-templates:

===============================
Data Templates and Instructions
===============================

A manifest [#f1]_ is a spreadsheet that helps you organise and record
metadata. Metadata is information that describes your data such as collection
date, instrument model or specimen ID.

A checklist [#f2]_ defines the metadata fields required for data submissions
based on the type of data you are submitting.

The terms *manifest* and *spreadsheet* are often used interchangeably.

.. _download-manifest-templates:

---------------------
Downloading Templates
---------------------

Manifest templates can be downloaded directly from the work profile component
[#f3]_ that you are working on (e.g. samples, single-cell, reads, etc.) by
clicking the |blank-manifest-download-button| button on each page. See the
:ref:`biodata-profile-components` or :ref:`tol-profile-components` sections
for more on accessing each component.

They can also be downloaded from the `Manifests page
<https://copo-project.org/manifests/index>`__ by selecting a type from the
dropdown menu then, clicking the **Download** button and choosing
**Blank template** option.

.. _fill-blank-manifests:

---------------------------
Recording Data in Manifests
---------------------------

Each manifest follows a manual known as *Standard Operating Procedure (SOP)*
[#f4]_ which provides a detailed guidance on how to record metadata in the
manifest.

The following are various ways to retrieve a SOP for a manifest:

#. Click the |sop-download-button| button located on the COPO **Samples** page
   to download the SOP.

   See the :ref:`accessing-samples-page-tol` component section for more
   details about accessing the **Samples** page.

#. Navigate to the COPO
   `Manifests page <https://copo-project.org/manifests/index>`__ -

   * Select a manifest option from the dropdown menu in the
     **Manifest/Checklist Type** column
   * Click the **Download** button for the desired manifest to reveal the
     download options
   * Click the **Standard Operating Procedure (SOP)** option to download the
     SOP.

     Please note that if the SOP does not exist, its download option will not
     be available.

#. The SOP for the various manifests are available below.
