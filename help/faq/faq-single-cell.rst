What is required for a Single-cell submission?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. collapse::   Click to view answer

   .. raw:: html

      <br>

   To create a Single-cell submission, you will need the perform the following
   submissions:

   #. :ref:`Samples <samples-submission-biodata>`: Upload and submit the
      sample data related to the Single-cell data.

   # :ref:`Files <files>`: Upload the data files pertaining to the Single-cell
     data.

   Thereafter, you can proceed to upload and submit the Single-cell metadata
   using a manifest file. See :ref:`single-cell-submissions` for guidance.
