=====================
Submission Statistics
=====================

Statistics are generated for each COPO instance over time and by a variable.
The statistics are automatically updated and can be accessed on the
`Statistics page <statistics-page_>`__.

.. raw:: html

   <hr>

Statistics over Time
--------------------

`Statistics <time-series-statistics-page_>`__ can be generated for the
following research object elements over time:

* Samples
* Data files
* Profiles
* Users

Statistics by Variable
----------------------

`Statistics <variable-histogram-statistics-page_>`__ can be generated for the
number of samples submitted based on the research elements or variables such
as -

* Date of Collection
* Sex
* Hazard Group
* Organism Part
