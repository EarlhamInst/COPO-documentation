.. _sample-update-notes:

Updating Samples: Important Notes
---------------------------------

.. note::

   Updates follow the same process as initial submission but, some field
   values cannot be changed. After the reuploaded manifest is successfully
   validated, the |confirm-button| button will appear. Click it to apply the
   changes.

   Refer to :ref:`samples-submission` for more information.

* Samples must be uploaded before they can be updated.

* Not all sample fields can be updated using the reupload method. The fields
  that can be updated are listed below (they are called *non-compliance*
  fields). The fields that are not listed cannot be updated; they are known as
  *compliance* fields [#f1]_. Click the |collapsible-item-arrow| icon to view
  the list of updatable fields.

.. raw:: html

   <br>

* You **cannot** reupload a manifest [#f2]_ with some of the existing samples
  removed. The removed samples (from the reuploaded manifest) will not be
  automatically removed from the manifest sample record.

  If you would like existing samples to be removed or deleted from the manifest
  record, please contact the :email:`COPO team <ei.copo@earlham.ac.uk>` for
  assistance detailing the profile title and reason for the removal.

.. raw:: html

   <br>

* If the manifest requires permits, the permits must be reuploaded before the
  manifest update can be completed. The |confirm-button| button will appear
  once the manifest validates successfully and the permits have been
  reuploaded.

.. raw:: html

   <br>

* The **Confirm** button will **not appear** if a manifest requires permits and
  the permits have not been reuploaded. The permits **must** be reuploaded in
  order for the **Confirm** button to appear when updating samples within a
  manifest. See the
  :ref:`Confirm button missing after manifest update and validation
  <faq-samples-update-successful-validation-but-no-finish-or-confirm-button>`
  :abbr:`FAQ (Frequently Asked Question)` for insights.
