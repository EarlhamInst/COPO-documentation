====================
Profile Types Legend
====================

The **Profile types** legend [#f1]_ is displayed at the right of the
**Work profiles** page. It displays the acronym as well as the corresponding
profile type colour for each profile that has been created.

.. hint::

   Hover over the |info-icon| icon located beside the profile type acronym in
   the **Profile types** legend, the backronym for the profile type will be
   displayed.
