==================================
Samples (within Biodata Profiles)
==================================

This section describes samples for a Biodata profile. If this section does not
apply to your use case and you are working with a
:abbr:`ToL (Tree of Life)` profile, please refer to the
:ref:`Samples (within Tree of Life profiles) <samples-submission-tol>` section.

   <hr>

.. _biodata-samples-types:

Types of Samples
----------------

Each sample type is outlined on the
`Manifests page <https://copo-project.org/manifests/index>`__. Alternatively,
see the :ref:`sample-manifest-checklists` section for an overview of each
sample type.

See :ref:`samples-submission-biodata` for information on how make the
submissions

.. hint::

   To view the description of each checklist type on the Manifests page:

   #. Identify the sample type in the **Category** column on the Manifests
      page.
   #. Click the dropdown menu in the **Manifest/Checklist Type** column. A
      popover will appear with a list of sample types.
   #. Hover over the sample type to view its description. The description will
      appear in a popover.

   Additionally, you can select a sample type from the dropdown menu, then
   click the **Download** button and choose **Blank template** to download a
   blank manifest. For more detailed guidance on submitting samples, refer to
   the :ref:`samples-submission-biodata` section.
