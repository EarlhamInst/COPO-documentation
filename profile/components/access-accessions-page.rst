Accessing the Accessions Page
------------------------------

Create a profile [#f1]_ following the steps in :ref:`profile-types`. Then,
access the **Accessions** [#f2]_ page via any of the following methods:

Using the Components Button
~~~~~~~~~~~~~~~~~~~~~~~~~~~

Click the |accessions-component-button| component button in the **Components**
[#f3]_ column as shown below:
