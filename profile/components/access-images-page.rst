Accessing the Images Page
~~~~~~~~~~~~~~~~~~~~~~~~~

Create a profile following the steps in
:ref:`Biodata profile creation <profile-walkthrough-biodata>`. Then, access
the **Images** page via any of the following methods:

Using the Components Button
^^^^^^^^^^^^^^^^^^^^^^^^^^^

#. Click the |images-component-button| component button in the **Components**
   column as shown below:

   .. figure:: /assets/images/images_comp/buttons/images_button_pointer_biodata.png
      :alt: Images profile component button
      :align: center
      :target: https://raw.githubusercontent.com/EarlhamInst/COPO-documentation/main/assets/images_comp/buttons/images_button_pointer_biodata.png
      :class: with-shadow with-border
      :height: 350px

      **Button to access the Images page (highlighted)**

   .. raw:: html

      <br>

#. Select an option to navigate to its page:

   .. figure:: /assets/images/images_comp/buttons/images_subcomponent_button_pointer_biodata.png
      :alt: Images subcomponents
      :align: center
      :target: https://raw.githubusercontent.com/EarlhamInst/COPO-documentation/main/assets/images_comp/buttons/images_subcomponent_button_pointer_biodata.png
      :class: with-shadow with-border
      :height: 120px

      **Dropdown menu showing image types**

.. raw:: html

   <br>
